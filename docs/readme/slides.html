RunQuest01. プロジェクト紹介01 / 04

AI によるパーソナライズド ランニングコース推薦サービス

RunQuest は、ユーザーの好みとランニング記録を分析し、一人ひとりに合った散歩・ランニングコースを推薦するサービスです。 運動経験と活動記録をもとにパーソナライズされたコースを推薦し、GPS 記録測定とコミュニティ機能で継続的な運動をサポートします。

RunQuest02. 背景と課題02 / 04

ユーザーの状態に応じて推薦基準を差別化

既存ランニングサービスの限界
課題 1

ユーザー一人ひとりの運動能力や活動履歴を十分に反映できていない場合があります。

課題 2

特に初心者や長期間運動を中断していた復帰ユーザーには、同じ推薦基準を適用しにくいです。

企画

ユーザーの状態に応じて推薦基準を差別化するパーソナライズド ランニングサービスを企画しました。

→
ユーザー状態別の推薦基準
新規

新規ユーザー

アンケートに基づくコース推薦

既存

既存ユーザー

アンケート + 直近のランニング記録に基づく推薦

復帰

復帰ユーザー

過去の記録 + 安全補正を反映した推薦
